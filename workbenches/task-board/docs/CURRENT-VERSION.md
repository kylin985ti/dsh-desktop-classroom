# 1.8.1 当前版本与验证范围

公开源码同步日期：2026-10-20。本目录保存任务栏工作台 1.8.1 源码、必要客户端构建产物、锁文件、许可和测试。同步保持工作台身份，不安装到正在运行的 DSH，不迁移任务。

## 已实现

开始规划 → 可选工作域扫描与正文取舍 → 主动生成 → 同一会话连续调整 → 图上预览 → 逐项接受 → 确认应用 → 整批撤销。每轮返回完整替代方案，可比较或退回版本；长解释和旧对话默认折叠。

新父任务、子任务和原有叶任务改期可同批接受；父级显示按完整选中候选树重算。确认前只更新预览；应用后详情与甘特图同步，重复确认禁用。撤销保护后续编辑和外来子任务，拒绝覆盖冲突。

1.8.1 仅排除宿主明确标记的运行环境/技能目录消息，修复自动回包被误拒收的问题；后续人工消息和未知来源仍阻止导入。当前规划会话连接在工作台实例内保留。关闭规划可恢复；整个工作台重载后不保留内存中的对话、版本或撤销凭据。

## 2026-10-19 的实际 DSH 服务验收

- 使用 CUA 浏览器连接桌面正在使用的实际 DSH 服务和公开原生 Session 接口，真实模型累计 3 次请求、3 个步骤，无工具事件；不是隔离模拟模型。
- 专用合成工作域扫描两篇正文，首轮排除其中一篇，第二轮主动加入；实际提示与 AI 引用一致。
- 同一会话完成两版建议；取消可选任务后，第二版未自动重新加入。版本比较、退回和切回、关闭规划/查看原生会话后恢复均通过。
- 1 项改期与 3 项新增（1 父 2 子）预览后确认，合成记录 23→26；详情、甘特图和磁盘结果一致。撤销后 26→23，全部准备记录逐字段恢复，容器保存时间更新。其他原有记录保持。
- 最终 AI 正文、候选树和结果一致；新父级随子任务提前一天重新汇总。另用新会话首轮验证自动接收，无需复制粘贴或手工救回。
- 已有本地规划 35 项、旧 AI 68 项、客户端 53 项、加载契约 28 项与包自检通过。GitHub 同步的检查与构建结果以本次提交的 Actions 为准。

## 保留的限制

- 完整流程的验证表面是实际服务的浏览器客户端。独立 macOS 桌面窗口只完成任务栏入口与专用总览检查；在打开样本前被用户切回另一个运行会话，没有完成其窗口内全流程，也不宣称该窗口已载入新版。
- 目录选择取消后的专用工作域由夹具准备，不计为原生目录选择器通过。
- 严格环境基线出现进程和宿主配置摘要变化，原因未核验，不能声称原进程和配置全程不变。该次验收没有执行 DSH 重启、终止或 View Reload，未覆盖这些环境变化。
- 日期均为人工给定的合成窗口，工期未知；不将其当作自主估期或所有学员设备、模型的保证。

本摘要不包含真实任务、会话原文、工作域资料、账号、原生窗口中的其他对话或运行配置。原始会话日志、任务快照和完整本机验收档案不随源码公开。
