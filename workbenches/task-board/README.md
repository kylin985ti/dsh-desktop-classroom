# 任务栏（dsh-task-board）

本地个人使用的 DSH Desktop 工作台。任务与子任务组织工作，工作域内就地阅读、编辑 Markdown 与代码；DSH 原生会话按需展开。不发布到应用市场，任务默认仅本机保存；主动使用 AI 时，仅在用户手动发送后由现有会话向其配置的模型提供所选任务上下文，不自动上传文件。

## 1.7.1：AI 父级汇总的前后日期口径

- 明确任务资料是提案前快照；AI 应先合并改期与新增任务，再按完整候选树重算各级自动父任务，正文单列「父级汇总变化」。父任务记录不写回，不代表其汇总显示保持旧值。
- 自动父级的旧汇总不作为固定边界；手动父级仍保持其自有边界。汇总包含未修改、已完成和废弃下级，并沿用工作台对仅截止日、缺日期和手动中间层的日期锚点口径。正文、理由、假设和工作域建议须与同一份提案一致。
- 导入数据格式与任务资料字段保持，旧版建议及关闭后的恢复继续兼容；实际预览与保存继续由同一个排期模型独立计算，不采信 AI 正文来写父级日期。

## 1.7.0：预览并确认导入新增任务与子任务

- 「导入 AI 建议」现支持新增任务、嵌套子任务和原有叶任务日期变更。预览先展示名称、父子层级、笔记与可选日期，统一确认后才一次保存；新任务均为待办，不填写负责人、工作域或实际完成时间。
- 分支内的新任务只能挂在本分支可用任务或同批新任务下；只有明确选择全部任务才能创建一级任务。新父任务自动汇总子任务日期；同级同名、循环/未知父级、已完成分支、手动父级越界和过期提案均阻止整批应用。
- 使用版本 2 的 `newTasks` 结构，最多 40 项；原有版本 1 继续只处理日期。旧回复里只有文字描述的新增任务不会被猜测创建，需要本版提示词生成明确的任务结构。
- 新任务使用本次请求与临时引用生成稳定标识，失败重试保持同一批身份；重复应用被拦截。既有记录与兄弟排序字段不因新增而重写。关闭面板后的原生恢复与手动完整回复导入仍可用。

## 1.6.4：一键导入原生 AI 建议

- 原生 AI 会话顶部增加「导入 AI 建议」，排期面板及旁边的返回条增加「导入本次 AI 建议」。等待回复完成后，点击即可读取当前本工作台会话的完整建议并展示日期差异，无需复制粘贴。
- 导入只读取、校验和预览，仍需另外点击「确认应用」才保存日期。生成中、其他工作台会话、请求不符、任务范围或计划已变化均拒绝；不自动发送消息、扫描文件或执行 AI 文字。
- 面板关闭后，可从已发送的中文任务资料恢复本次上下文，前提是所选范围及任务资料仍一致；已经应用或过期的旧建议不能再次应用。没有新增跨会话扫描或持久化聊天缓存。手动完整回复导入继续保留。

## 1.6.3：中文可读的 AI 往返与当前阶段说明

- 发送任务与文件资料时使用中文标签、真实段落和换行，不再把正文放入带 `\\n` 转义的整包 JSON；内部请求快照仍在本地保留，用于校验范围与过期状态。
- AI 先给中文排期与工作域建议，末尾的「工作台导入数据」单独放在 JSON 代码块中。可直接复制完整回复导入，无需手工拆分；旧版纯 JSON 仍兼容，多份数据、其他代码块和 HTML 继续拒绝。
- 明确当前流程为生成建议、导入预览、用户确认应用；历史资料中的旧验收阶段不能替代当前流程与授权。已写入草稿的提示不再冒称原生消息一直未发送。

## 1.6.2：Desktop 工作域扫描与原生草稿

- 绑定工作域时与 DSH 官方目录流程一致，优先使用 Desktop 原生目录选择接口；没有该接口的浏览器宿主保留既有工作区选择方式。
- 取消或失败只返回本次结果，不继续弹出第二个选择器；原有工作域绑定和任务数据保持。
- 显式声明原生会话控制器与会话输入框服务依赖，修复宿主因未声明依赖而禁用原生草稿入口的问题；工作台归属、空白草稿、附件与发送保护继续生效。

## 1.6.0：拖动改期、层级示意与可选工作域建议

- 拖动甘特横条平移计划，拖动两端调整起止日期；先显示预览，松开后保存到详情所用的同一份计划。Esc 可取消；越界、日期颠倒或保存失败时保留原计划。仅有截止日的菱形也可拖动改期。
- 平移父项目时整个分支一起移动，包含隐藏的已完成下级；调整父项目两端时保留子任务日期，超出边界则整批拒绝。自动汇总项目调整两端会明确改为手动计划。
- 支持键盘：横条 Alt + 左右键平移，两端左右键调整；Shift 每次 7 天，Enter 保存，Esc 取消。正常单击仍打开详情。
- 父子层级增加稳定编号、缩进连线、分支边线和项目标识；「操作与层级示意」说明折叠、颜色与拖动规则，横条仍按任务状态着色。
- AI 面板增加默认关闭的「读取工作域辅助排期」。主动选择并扫描所选任务或父级已绑定的文件夹后，可检查递归文本索引和已读正文、逐篇取消正文，再预览完整提示词。文件名使用相对路径，绝对工作域路径不加入提示词。
- 扫描只读，跳过隐藏文件、常见凭据、依赖和构建目录；最多 400 个索引候选、120 个文件名、12 篇正文、合计 16000 字。未读或截断内容不能视为已审阅；不是完整代码审计。扫描不调用模型、不发送消息、不写文件。模型可返回工作域推进建议，只展示供参考。

## 1.5.4：甘特图默认隐藏已完成任务

- 甘特图默认不显示已完成任务（包括当天刚完成）；已完成父项目的整个分支一起隐藏，其他项目中的未完成任务继续显示。
- 工具条增加「显示已完成」开关，可恢复查看历史任务与全部下级。开关只控制展示，不改变状态、日期、负责人或任务数据。
- 全部任务与单个项目分别记住当前工作台内的开关、折叠和滚动位置；重新加载工作台时恢复默认隐藏。已废弃任务沿用原有显示规则。
- 隐藏项目不再参与时间轴范围和负责人列计算；自动父任务的计划仍基于完整原始任务，避免筛选改变原有汇总日期。空范围提供明确的显示已完成提示。

## 1.5.3：仅保留任务日历

按用户要求移除本地 macOS 日历连接：不再提供连接、授权、来源列表或系统事件叠加；不打包或启动原生日历助手，也不注册相关后端接口。历史版本与验收记录保留在本地归档中，不属于当前安装包。

- 顶部「日历」显示全部任务，详情「查看日历」可查看当前任务及全部后代；点击任务回到原详情，返回时保留月份、筛选与滚动位置。
- 任务计划直接投影为跨日横条，不复制成另一份事件。起止日期包含首尾当天；只有完成日期显示截止点；没有完成日期保留在待排期列表。五状态、历史任务、父级自动汇总、拥挤日期完整列表和原计划编辑流程继续保留。
- 支持滚轮/触控板连续跨月：当前月前后各一月组成 13–15 个去重周，跨月后保持可见日期与像素位置，滚动只发生在日历内部。
- 点击月标题可快速选择年份和月份，保留前后月、今天与日期键盘导航。日期范围为公历 0001–9999 年。
- 保留任务数据与原生 AI 会话；移除本地日历连接不触碰系统授权设置。

## 1.4.0：甘特图与个人排期

- 顶部「甘特图」默认隐藏已完成任务及其下级，可用「显示已完成」查看历史；详情「查看甘特图」只显示当前任务及其全部层级子任务。点击图中任务进入详情后，可返回原范围、折叠和滚动位置。
- 借鉴 Instagantt 的左任务树/右时间轴结构，不复制品牌素材。任务/负责人/日期固定在左侧，图表内部滚动；保留五状态配色、今日竖线、截止日期点、层级折叠及未排期提示。
- 计划字段为 planStartDate、planEndDate（严格 YYYY-MM-DD，按自然日）、planMode（auto/manual）和可选 assignee。旧任务缺字段仍正常读取，不补写或迁移。读取响应另带 scheduleProtocol 能力标记（不写入数据文件）；新界面遇到尚未重启的旧服务会禁用写入并提示 ⌘Q 重开，避免旧服务静默丢失新字段。
- 首次打开计划编辑时，手动计划的开始日期预填本地当天；保存后才写入。完成日期不猜测、不按当天自动补齐；清除日期可保留未排期。
- 有起止日期绘制包含首尾当天的条形；只有完成日期显示截止点；没有完成日期保留空轴并提示「请备注起始和完成时间点」。负责人未填就留空，不提示补充、不继承、不邀请成员。
- 父任务默认自动汇总已排期下级范围，标识未完整排期；手动设置后成为明确边界。检查全部层级的起止时间，父级缩短和子任务改归属也需校验，冲突不静默延长父级或移动子级。
- 计划日期与状态/实际结算时间独立。日期到了不自动标记完成；完成/恢复不覆盖排期。未排期的持续性工作不虚构结束日期。
- 甘特图固定日粒度，保留日期横轴、今日定位与排期定位；1.5 增加月历，1.6 增加拖拽改期。依赖箭头和关键路径尚未实现。

### AI 辅助排期（建议式）

1. 选择任务分支（全量任务必须显式选择），可补充总截止日期与要求；可选主动扫描已绑定工作域，检查文件内容后再在本地预览所选上下文。
2. 点击「放入原生会话草稿」只填入本工作台归属的空白草稿，**不自动发送**；已有文字/附件、会话归属不明或切换会话时拒绝覆盖。若宿主能力不可用，可选中或复制提示词手动使用。
3. 用户在 DSH 原生会话中手动发送，回复完成后点击会话顶部「导入 AI 建议」或旁边「导入本次 AI 建议」，直接校验并预览。也可复制完整回复手动导入；不会后台抓取聊天或自动应用。
4. 预览原有日期差异、新增任务及父子层级、笔记、理由、估算假设和冲突；点击「确认应用」后才一次性提交。原有任务只接受范围内可排期叶任务的日期；新增待办任务可带笔记和可选计划，不改已有任务的负责人、状态、笔记、工作域或实际结算时间。
5. 非法日期、父级越界、重复/范围外 ID、额外字段及提案生成后任务已变化等情况均阻止应用。持续性工作默认不建议结束日期，除非用户明确允许；完成/废弃保留原计划。

只有明确点击「选择位置新建会话」才调用宿主目录选择器；不自动扫描工作域或读取文件。AI 的工期只是建议，不是已知的真实截止日期。计划/负责人草稿与文件草稿都需在导航前保存、明确放弃或取消。

## 1.3.0：保持横向 + 持续性工作

沿用 **Linear 的紧凑信息层级 + Todoist 的看板结构**，只改业务面板，不替换宿主侧栏。

根据 1.2.0 重启后的使用反馈，移除看板列数的宽度断点：不再因窗口稍小而跳成 2×2，也不在窄窗改为上下堆叠。

- 浅灰底、白色任务卡、轻边框与低饱和蓝紫强调色；支持系统深色偏好。
- **待办 / 进行中 / 持续性工作 / 完成 / 废弃始终单行横排**。每列最窄 250px，窗口宽时按可用空间伸展，窗口窄时仅看板内部横向滚动，工具栏、总览统计和整个页面不横向溢出。
- 看板可用触控板、Shift+滚轮、滚动条横移；焦点在看板区域时，左右方向键逐列移动，Home/End 到最左/最右；拖拽到左右边缘可自动横向滚动。
- 任务名与状态 tag 同行。长标题只在自身区域换行，不挤掉状态与操作菜单。
- 点击任务名进入详情；「···」集中打开任务、添加子任务、标记完成/恢复、移动、删除等操作，不再常驻一整排按钮。
- 每一级子任务都有直接新增入口；树形折叠、草稿与展开状态在普通界面更新中保留。
- 详情将笔记、子任务放左侧，工作域与文件阅读编辑放右侧；窄窗口自动变为一列。
- 总览、详情共用一个工具栏与一个原生会话抽屉。抽屉默认关闭且不占布局，展开后不遮挡工具栏。
- 新建任务改为轻量对话框，归属可选任意层级；各列新增入口会预选该列状态。

**本轮没有加入草图中拟议的搜索、筛选和列表切换。**

## 核心流程

1. 从宿主「工作台」切换到「任务栏」，直接查看任务总览，无需先建会话。
2. 点击「新建任务」或某列的「＋」，填写标题、归属和状态。
3. 点任务名进入详情；标题与笔记在失焦后保存，标题也支持 Enter 提交，不在每个字符输入时写盘。
4. 通过每一级旁边的「＋」、根卡展开后的入口，或「··· → 添加子任务」，就地创建下级任务。
5. 在详情选择文件夹作为工作域，必须经过宿主目录选择器，由用户确认。取消选择不建目录、不写绑定。
6. 列出该工作域内的文档和代码；文件扩展名决定 Markdown 阅读或代码着色，均可切换纯文本编辑并保存。
7. 需要 AI 协助时才展开「AI 会话」，由宿主提供真正的原生会话；没有会话时提供宿主工作区/会话初始化入口。

## 数据与可见性

一级任务与子任务都有独立的五档状态，**组头只统计一级任务**。子任务不会重复计数，也不会由父任务状态自动覆盖。

「持续性工作」是长期保留的独立状态（内部键 ongoing），适合日常维护、持续跟踪等工作；不受更新/创建日期或历史开关影响，不自动创建周期任务、提醒或复制记录。可在该列直接新建，也可用状态菜单、拖拽或键盘将已有任务移入/移出；进入该状态清除结算时间，明确转为完成/废弃后才按正常结算规则处理。现有四类任务不自动改状态或迁移。

完成与废弃的根任务只在结算当天出现在默认总览，次日隐去；「查询历史」包含往日结算，「隐藏往日结算」恢复默认口径。时间按本地时区计算。仅调整顺序或重复选择相同状态，不重新结算历史任务。

任务数据由配置的 DSH 数据目录持久化，工作域文件保留在用户选定的目录。卸载插件不会删除任何上述数据。

```text
DSH_HOME/task-board/tasks.json   任务、父子关系、状态、笔记、工作域与手动位次
用户选择的工作域/               原有 Markdown、代码及明确新建的文件
```

## 交互与安全保护

### 拖拽与移动

使用真实 Pointer Events，而非原生 HTML5 拖拽。手柄移动超过 5px 起拖；触控、鼠标与键盘状态切换共用任务状态口径。

| 落点 | 操作 | 提示 |
|---|---|---|
| 进度列标题或空白区 | 改变当前任务状态 | 列虚线高亮 |
| 任务标题行上缘 25% | 同级排序，放到它前面 | 上边线 |
| 任务标题行下缘 25% | 同级排序，放到它后面 | 下边线 |
| 标题行中间 50%，稳定悬停 0.5 秒 | 成为它的子任务 | 先虚线待确认，后实线确认 |

边缘与中心的命中区域按**独立标题行**而非整个展开子树计算。未确认的中心松手为完整 no-op；指针移动超过 8px 或离开候选节点会重新计时，松手时重新检查实际落点。不能移入自身或自己的后代。Escape、失焦、取消指针、切换视图与组件卸载均清理拖拽监听和高亮。

子任务的结构调整只改变排序/归属，不借用根任务所在列的状态；根任务跨列边缘排序按目标列改变状态。状态、排序、归属意图在一次功能更新中组合提交，避免旧快照覆盖。排序依据当前显示的兄弟顺序，不依据原始数组顺序。

「··· → 移动到…」提供明确归属选择，可以把任意子任务恢复为一级任务。新父级选项排除自己与全部后代。

### 删除

删除需要确认，并说明涉及的下级任务数量。确认后删除整个任务记录子树，取消不做修改。**不会删除工作域文件或文件夹。**

### 菜单与键盘

状态菜单和操作菜单共享一个位于业务根容器内的浮层，不放在滚动卡片内部。浮层按真实尺寸约束在业务面板内，靠底部向上翻转，滚动/调整窗口后关闭；支持方向键、Escape、外部点击与焦点返回。对话框限制键盘焦点到自身，避免误操作背景。

### 持久化

- 成功载入任务前、以及载入失败时，禁用所有新增和写入入口。错误有「重新加载」入口。
- 全量任务保存使用客户端串行功能更新队列与同步 live ref，失败只回退适用的最新快照；草稿成功确认后才清空。
- 服务端使用唯一临时文件和串行原子写，保留未修改任务的时间戳与手动排序信息。
- 只有任务数据文件真正不存在时才按空状态处理；损坏或不可读时明确报错并保留原字节，不能覆盖成空列表。
- 数据结构版本仍为 1，不迁移用户文件；没有加入跨窗口版本锁。多窗口同时编辑同一完整任务状态仍可能最后写入者优先。
- 旧版 1.2.0 不认识 ongoing；如果之后需要回滚到旧版，应先把持续性工作移回原四类之一，不能直接用旧版打开含新状态的数据文件。旧安装包仍保留，但不以回滚代替新状态转换。
- 1.3.0 及更早的服务端不保存计划/负责人新字段。若确需回滚，先完整备份新版本任务数据，不能在旧版继续编辑后期待排期字段仍保留。

### 文件编辑

文件切换、任务/总览导航或解除绑定前，有未保存内容时提供「保存并继续 / 放弃修改 / 取消」。普通状态、折叠、会话开关不会重置当前文件草稿。迟到的文件响应不会覆盖后选文件，保存中的新输入仍标记为未保存。

「新建文件」只接受当前工作域内的文件名。服务器独占创建：同名文件返回 409，**不会清空原文件**。路径接口要求绝对路径、已登记的工作域边界，并检查解析后的根目录、目标文件或创建父目录，拒绝符号链接逃逸；一般 realpath 检查不承诺抵抗恶意并发文件系统替换。

## 本机接口

全部使用工作台自己的 `/api/dsh-task-board/` 前缀：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/dsh-task-board/state` | 读取任务 |
| POST | `/api/dsh-task-board/state/write` | 保存完整任务状态 |
| GET | `/api/dsh-task-board/files?path=` | 工作域文件列表 |
| GET | `/api/dsh-task-board/file?path=` | 单文件读取 |
| POST | `/api/dsh-task-board/file` | 保存，或明确独占新建 |

文件 GET/POST 合并为一条宿主路由，避免相同 exact 路径重复注册。

## 宿主集成与安装

客户端只从宿主共享基线获取 React；自有模块与样式预构建到单文件。工作台身份仍由原 repository 推导，使用 `customFrame: true`。主根的第一个元素一直是语义 header；原生 conversation 只挂载一次，抽屉从测量后的工具栏底部开始，不越过业务边界。

本机通过本地安装包更新既有 web profile，保留其他插件、配置和任务数据。没有启动替代 GUI，也不自行终止当前 Desktop/Harness；**安装后需要用户 ⌘Q 再打开**，重启后界面与真实原生会话仍需用户确认。

Desktop 0.11.1 的 generation 投影曾对本包的宿主提供依赖记录 deferred 校验提示。隔离 Web 宿主加载可验证包、注册、业务 UI 和接口，但不能证明重启后所有原生投影/会话状态；不把这个限制描述为已修复。
