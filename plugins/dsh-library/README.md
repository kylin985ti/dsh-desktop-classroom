# 资料库 · 0.4.3-classroom.1

DSH Desktop 教学套件的本地文件阅读与编辑插件。文件保留在原位置，原有索引、草稿与文件协作历史继续使用。

0.4.1 增强块拖拽落点：实色蓝线、圆点和「放到这里」标签，并保留编辑器原有的定位与移动逻辑。AI 服务的超时、连接、认证、额度和配置失败分别提示，不再误报为文件读取权限；失败保留问题与正文，日志只记录错误分类，不记录提供方原始响应。

0.4.2 将 Markdown 阅读与编辑合一，打开后直接修改。选区格式、引用与 AI 协作放在同一条工具栏，并使用前景色显示图标。文件内 AI 明确区分“仅这段”和“结合全文”，来源卡、说明和真实模型输入保持一致。

0.4.3 修复全局侧栏资料库入口缺少图标：书本图标独立声明 16×16 尺寸与线条样式，随侧栏文字颜色显示，不再依赖正文区域的 CSS。

## 已知限制与加载

浮动工具栏仍可能遮挡上方标题，定位问题待修。0.4.3 入口图标已通过浅色、深色与收起状态的隔离预览，正式加载后的显示仍需复核。安装后等待任务空闲，由本人重启 DSH。公开版 Office/PDF 使用宿主运行时和随包 pypdf，保留其许可证；不包含架构绑定 PDF 可执行文件。完整安装及学员验收见仓库的 docs/LIBRARY.md。

## 界面与使用

- 左侧资料导航：最近打开、收藏、按已加入文件名搜索、我的文档与已连接文件夹；收藏与最近顺序仅保存在本机浏览器。
- 新建和添加入口集中在资料库标题旁的「＋」，支持 Markdown、HTML、CSV 与文件夹。文件夹仍按需展开，不遍历整台磁盘。
- 多文件标签最多 12 个。每个文件独立保留正文、视图与协作状态；关闭标签时保留未保存草稿。
- 文档顶栏仅保留面包屑、AI 协作、引用到对话和更多菜单。源文、刷新、撤销上次保存、另存副本、重命名与打开方式收进更多菜单。
- 全局 DSH 侧栏不改写、不强行调整宽度。资料库提供公开接口支持的「收起 / 展开全局侧栏」，也能单独隐藏资料导航。

## Markdown

打开即展示可直接编辑的 Milkdown / Crepe 正文，无需切换“阅读 / 编辑”。在正文中输入、排版或拖动，原有撤销历史和自动保存机制继续使用。更多菜单提供源文入口；进入后标记“源文模式”，可点击“返回正文”。

- `/` 菜单直接提供 **H1 一级标题、H2 二级标题、H3 三级标题**，不需进入子菜单。使用固定的无衬线字体、字号、字重和段距。
- H4–H6 只从快捷菜单隐藏；原有文件中的这些标题仍可正确解析和保存。
- 保留列表、待办、表格、引用、分割线与代码块等编辑能力；块手柄、格式栏按需出现。
- 选中文字出现一条格式与协作工具栏，含加粗、斜体、删除线、行内代码、链接、引用与 AI；图标区分正常、选中和禁用状态，支持键盘激活并保留选区。源文编辑也能捕获选区。选区超过 12000 字符会明确拒绝，不会悄悄截断。
- 安静的目录入口列出 ATX 格式的 H1–H3，并跳过 fenced 代码块。不能精确匹配的目录项不会猜测跳转；Setext 标题暂不列入目录。
- 停顿约 850ms 自动保存（另有编辑器变更通知延迟）；连续自动保存沿用 30 秒撤销合并。外部变更暂停写回并保留草稿，可刷新或另存副本。

## 引用到对话

1. 选择一段正文后点击浮动工具「引用到对话」；没有选区时，文档顶栏入口引用整份文件。
2. 右侧显示来源卡片：文件名、选区快照或文件预览、路径 / 章节、定位原文、移除入口。
3. 选择新会话或最近的已有会话，并填写可选附加要求。新会话关联文件所在的已有工作区；不存在对应工作区时才创建文件目录工作区。
4. 点击「加入会话草稿」后，将原生引用卡片加入目标会话，不替换已有草稿、不自动发送、不调用模型。最后仍由用户在原生输入框主动发送。
5. 选区引用只展开所选文字；整文件引用只传递路径，由会话按需读取。用于本地过期比较的全文快照、预览和哈希不进入引用 payload。
6. 正文变化时提示引用过期，需主动更新或重新选择。加入草稿前对可编辑文件再次校验磁盘版本；不可编辑文件的选区是读取时快照，整文件引用是动态路径，不承诺磁盘内容已冻结。

会话输入框的交接等待其挂载、原生草稿恢复与 mirror 绑定，再进行同步原生 CAS 插入，并回读引用条目确认成功。取消、超时、会话切换或插入失败不会清掉待引用快照；引用待稿在插件本次运行期间最多缓存 32 个文件，重启后的引用待稿不作持久化承诺。

## 原有文件编辑与 AI 保护

CSV 保留网格、添加行列、分页、源文与手动保存；网格限制 5000 行、100 列、1MB，不静默丢弃未展示数据。HTML 保留隔离交互预览、同目录资源、静态文字修改和源文编辑；写回基于原始源文，不保存运行时 DOM、临时 blob 或编辑器属性。Office、PDF、图片与音视频保留原读取 / 预览与系统应用打开能力。

「AI 协作」仍使用文件专属历史与配置模型。从选区进入时默认“仅这段”，模型只收到选中内容与本次问题；主动选择“结合全文”才加入全文上下文，修改目标仍是选区。没有选区时明确显示“整篇正文”。切换到引用会话时仍遵守原引用白名单，整文件引用只传路径。

浏览器和服务端共用长度及范围校验：选区最多 12000 字符，问题最多 4000 字符，最终序列化的模型输入最多 300000 UTF-8 字节，超出明确拒绝，不静默截断。长文件的短选区不再被全文大小拦住。完整源文只在本地前后端用于版本比较和安全合并，不会因选择“仅这段”而进入模型请求。旧客户端未传范围但提供选区时也默认仅该选区。

选区快照过期时先更新或重新选择；提交前校验磁盘版本。建议先展示差异，接受后才保存；拒绝不写文件。唯一选区仅替换原段，重复 / 跨格式选区不猜测；正文变化、外部修改、过期建议均有保护，接受后可撤销。连续追问历史拼接、流式输出与停止请求属于后续范围。


- 本地构建入口：[构建脚本](<scripts/build-editor.mjs>)；编辑器、CSS 与字体全部本地打包，不依赖远程样式。
- 界面代码：[客户端](<src/client-base.js>)、[样式](<src/library-ui.css>)、[Markdown 编辑器](<src/markdown-editor.js>)、[引用模型](<src/library-model.js>)。
- 后端保存与冲突机制：[服务端](<lib/index.mjs>)、[存储层](<lib/store.mjs>)。0.4.0 没有改动这两层。
- 合成数据测试涵盖自动保存 / 撤销、外部冲突、并发保存、草稿、AI 建议接受 / 拒绝、引用白名单、只读切换、选区与交接生命周期；不会调用真实模型。
- 实际 DSH Host 的隔离浏览器可精确替换单个客户端 bundle 做新版集成测试，原 Host、其他插件和桌面窗口不因此升级。此种测试必须标注为测试覆盖层，不能冒充已部署桌面视觉验收。

现有 DSH 版本替换已安装插件会返回 `restart-required`。使用单插件 generation 安装，不覆盖旧 immutable generation、不运行全量 profile 安装；须在允许重启 Host 后才能验收正式生效的新版本。仅刷新页面不足以激活。
