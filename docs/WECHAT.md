# 微信数据库自动接收（实验功能）

从教学包 0.2.0 起包含本机连接器，默认关闭。每位学员独立授权、选择账号和群；没有预设账号、群名或群 ID，也不导入教师的钥匙串或聊天。微信系统“发送到 DSH”分享扩展仍未分发，文件导入继续可用。

## 学员接通步骤

1. 先完成一键安装，空闲后重启 DSH。打开 **群聊简报 → 自动接收 · 连接设置**。
2. 打开自己的电脑版微信并登录，点击 **打开本机连接器**。在连接器下拉框选择自己的账号目录；多个历史目录不会自动选为授权范围，先核对所选账号。
3. 点击 **授权所选账号并存入本机钥匙串**，仅在 macOS 的标准管理员弹窗输入密码。扫描最长90秒，之后进行数据库页/结构验证；密码、密钥、验证码均无需提供给老师或 AI 助手。
4. 看到保存成功后回到 DSH，点击 **刷新连接 → 加载 / 刷新群列表**。这一步只读取群名和群 ID，不读取聊天正文。勾选1至10个要接入的群；同名群核对 ID，点击 **保存所选群并暂停同步**。
5. 选择最近1、6或24小时，点击 **开启所选群自动接收**。首次同步后监听该账号的消息目录变化，无定时轮询；微信和 DSH 需要运行，历史消息必须已在本机。
6. 记录按账号、群身份、日期分别进入左侧接收箱。选择记录并点击 **整理成一段话** 才调用自己的模型；自动同步本身不调用模型。

更换连接器中的账号或保存新的群范围会使自动接收暂停，旧结果不会导入新的范围；本人再次开启后才继续。这里只更换 DSH 的读取绑定，不自动识别或切换微信登录状态。若在微信切换了登录账号，请先暂停，在连接器中重新选择并授权。

点击 **暂停自动接收** 停止监听和正在进行的读取。点击 **断开并删除本机钥匙串授权** 删除该连接的密钥，已经接收的本地简报仍保留；不删除微信原始数据。重新安装教学包不会复制或更改学员的授权配置。

## 兼容范围与故障

- 连接器要求 **macOS 13+**；Apple Silicon 本机编译和合成加密数据库测试通过。提供 x64 构建，尚无 Intel 真机验收。Desktop 本体仍支持清单列出的 macOS 最低版本。
- WCDB 配置布局参考 **macOS 微信 4.1.13** 的开源适配。其他版本、指针布局、系统安全策略和企业设备管理均可能使授权失败；不承诺兼容所有微信4.x版本。
- 管理员授权不保证系统允许读取进程。拒绝访问、未匹配全部密钥、新增未知分片或结构不兼容时停止，显示错误；不会把失败报告成“0条消息”。不会自动重新签名/注入微信、修改系统保护或退出微信。
- 连接器是源码公开的临时签名构建，**尚未 Apple 公证**。系统提示无法打开时，核对本仓库 Release 和 SHA256 后，使用 macOS“隐私与安全性”的本人允许入口；不关闭 Gatekeeper，不执行解除全局保护的命令。
- 当前读取最近24小时内的本地群文字；图片、语音、视频等只显示类型，语音不转写，不下载媒体。每群最多4000条、每分片1000条；过多时缩短范围。
- 快照会短暂占用磁盘；APFS 优先写时复制，其他文件系统单个库上限1GB、单次物理复制上限4GB。快照保持加密，读取完成/取消后清理；不导出明文数据库。突然断电留下的私有临时快照仍为密文。

## 本机数据与隐私

连接器安装于 `~/Applications/dsh-classroom-wechat/0.2.0/`，不修改 Desktop 或微信应用包。SQLCipher / zstd 随连接器提供，不需要 Homebrew 或全局 Python；Python 使用已安装 Desktop 自带运行时。

数据库密钥只保存在本机 macOS 钥匙串的课堂版独立 service 下。授权时通过私有 FIFO/标准输入传递，命令行参数、扫描器输出和安装回执不含密钥。连接元数据和选群信息仅保存在本人的 DSH home：`storages/wechat_digest/database`。接收记录在 `storages/wechat_digest/documents`。这些运行时目录禁止提交到公开仓库。

原始微信数据库只复制加密内容，在私有快照上用 SQLCipher 只读查询。聊天查询按所选群 ID 的精确哈希表名执行；私聊和其他群的正文不作为查询范围。群列表需要读取本账号的群名元数据，发言人显示名仅按所选消息中的发言人查询。

本功能不是访问控制沙箱：同一 macOS 用户下的恶意程序仍可能读取你的本机文件，管理员拥有本机权限。不要在共享系统账号下接入私人微信。同步到 DSH 的内容由你管理；向模型整理前先确认使用的服务和内容范围。

## 开源参考和验证

配置布局参考 wechat-cli 的两个固定提交，匹配器参考 wechat-suite；SQLCipher 4.19.0 使用 Apple CommonCrypto，zstd 1.5.7。具体版本、源码 SHA256、许可见 `plugins/dsh-wechat-digest/native/dependencies.json` 与 [第三方说明](../THIRD_PARTY_NOTICES.md)。

公共测试只使用合成数据库、自进程内存和独立 DSH home，不使用教师授权、账号或群。系统授权、学员微信版本和首次真实读取仍需本人按 [验收清单](ACCEPTANCE.md) 完成；不要将真实聊天、连接文件、钥匙串导出或完整诊断日志上传到 issue。
