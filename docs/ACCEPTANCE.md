# 学员验收清单

安装回执代表包已安装；只有重启后的界面和实际账号测试才能确认可用。默认不调用模型、不上传真实文件。

| 项目 | 验收动作 | 通过标准 |
| --- | --- | --- |
| 原生安装 | 执行 `bootstrap.sh --doctor` | 清单内 9 个插件版本一致 |
| 加载 | 空闲后重启，查看原生插件页与启动错误 | 出现对应插件，无新增启动错误 |
| 自己的模型 | 在本人选定的 provider 发一条合成问候 | 实际收到回复，记录所用 provider/model |
| 预测 | 完成一个合成回合，等待候选 | 灰色候选可见；Tab 仅填草稿，Esc 忽略；有文字或附件草稿时不覆盖 |
| 引用 | 选中 AI 回复的一段，选择引用当前会话，再写评论 | 引用以卡片呈现；评论与原文关联；发送后正常展示；侧栏提问也可用 |
| Markdown | 新建学习用 `.md`，输入标题、列表、加粗，再重新打开 | 打开即可编辑，无需切换阅读/编辑；自动保存后内容仍在；更多菜单可进入源文并返回正文 |
| 资料库入口 | 检查展开、收起侧栏及本人当前主题 | 资料库前有书本图标，入口文字对齐，点击仍进入原资料库 |
| 资料库 AI 范围 | 用合成 Markdown 选中短句，对比“仅这段”和“结合全文” | 来源卡与范围一致；仅选区不包含段外内容；长文短选区可提交；过期快照先更新；建议接受前不写入 |
| 资料库格式与拖拽 | 选中文字、使用格式、引用和 AI；拖动学习用段落后撤销 | 图标可见且支持键盘；引用仅加入草稿、不自动发送；落点可见，保存与撤销准确。浮动栏遮挡标题是已知待修项，不标记为完整通过 |
| HTML / Office / PDF | 本人选择无隐私样例，打开 HTML 交互、读取 Office/PDF | HTML 可操作；Office/PDF 提取正文；无正文/扫描件明确提示 |
| 文件协作 | 对学习用文件提出一个具体修改 | 先见差异预览，确认后写入；外部变化产生冲突提示 |
| 腾讯文档授权 | 在输入框底部图标打开腾讯文档浮层，本人完成官方 OAuth | 授权后账号自动连接；勾选本会话启用后才向 AI 提供工具；失败保留授权可重连，不显示或导出 Token |
| 会话连接选择 | 在两个学习会话分别勾选/取消“本会话使用腾讯文档”，重启后检查 | 默认关闭、选择独立保留；关闭后本会话工具不可用，账号和其他会话不受影响；输入框外没有常驻状态块 |
| 连接器会话入口 | 从连接器卡片“去会话”，或在输入区展开连接器 | 当前会话、文字及附件草稿保留，不自动填入或发送；无会话时走宿主新会话流程 |
| 腾讯文档读取 | 在会话粘贴本人有权限的测试链接，要求只读并核对结果 | 实际执行官方 MCP 读取；工具发现不等于文档可读；PPT/图片未返回内容时明确说明 |
| 腾讯文档修改 | 开启修改建议，生成一个测试提案，先拒绝再提出 | 确认前无写入；审阅显示目标和完整参数；只执行本人确认的一项，写后只读核对 |
| 腾讯文档审阅取消 | 在审阅弹窗按 Esc，再从列表拒绝提案 | Esc 只关闭弹窗且保留待确认项；拒绝终止提案，两步均不写入文档 |
| 连接器会话归属 | 在两个学习会话提出合成建议并切换查看 | 输入区只显示本会话建议，不能从该入口确认其他会话的提案；历史项仍在管理页 |
| 腾讯文档边界 | 修改前在官网改动相同内容，或在检查时关闭修改权限 | 冲突/权限变化阻止写入；断开使旧提案失效；结果不明不自动重试 |
| 群聊简报 | 粘贴合成的 2～5 条聊天，命名和备注，再生成简报 | 接收时间可见，简报为一段话，能查看对应原话；导入本身不调用模型 |
| 微信数据库（自选） | 按 [接通步骤](WECHAT.md) 本人授权、核对账号，选一个自己的测试群后开启 | 默认关闭，选群前不读正文；只出现所选群；暂停停止监听，切换连接暂停；断开删除钥匙串授权，已收到记录保留；不兼容明确报错 |
| MCP / Skills | 查看列表，需要修改时先选一个学习用项目 | 配置可见，添加/修改明确落在本人目录；不复制教师设置 |
| Tavily | 本人配置 key 与 provider，再明确同意一次测试 | 实际搜索返回可打开的来源；只有 key 已保存不算接通 |
| 持久化 | 保存合成草稿、资料库编辑与导入记录，空闲后冷重启 | 会话、草稿和记录可重新打开 |

遇到缺失账号、平台未验证、模型下架、权限不足时保留为待完成项。不要用“安装成功”覆盖这些状态。


腾讯文档 0.4.0 起不提供自建文档列表、版式预览或网页截图引用。原网页使用官网；旧接收数据保留但不自动迁移。没有真实样例或空闲窗口的项目明确保留为未验收。
