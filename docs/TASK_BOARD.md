## 单独构建与安装

使用 Node.js 22+ 与 pnpm 10.34.5，在工作台目录执行：

```bash
cd workbenches/task-board
pnpm install --frozen-lockfile
pnpm build
pnpm test:planning
pnpm check:package
pnpm pack
```

生成的 `dsh-task-board-1.8.1.tgz` 可通过本人 Desktop 的插件安装入口或原生 CLI 加到本人确认的 web profile。仓库不保存维护者的原始安装包、DSH home、profile、任务或凭据。工作台与默认插件分别安装。

工作台身份保留为 `xudingsheng/dsh-task-board`，用于兼容既有状态；此字符串不是当前源码托管地址。不要只为调整 GitHub 路径而改变它。

安装不等于界面及模型验收。若宿主要求重载，等待本人确认的空闲窗口，不中断正在运行的任务。用合成任务与合成工作域验收，不申请系统日历权限或读取真实日程。

## 规划流程

1. 在甘特图点击「AI辅助排期」，选择项目分支并说明目标。工作域默认关闭；需要时主动勾选、扫描并预览，可以排除某篇正文。
2. 点击「生成方案预览」才向新建的本工作台原生会话发送资料；已有会话草稿和附件不会被覆盖。生成中不修改任务，取消或失败不自动重发。
3. 在同一输入框继续调整，每轮生成完整方案；旧对话和长解释默认折叠。可比较版本差异、退回上一版，再切回需要的版本。
4. 图上叠加原计划、建议改期、新父任务及子任务，侧栏逐项接受。接受新子任务会包含其新父任务；取消新父任务会取消它的新下级。未接受项不参与父级汇总，也不在下一轮自动加入。
5. 点击「确认应用所选」才一次保存接受的新增与改期；任务详情和甘特图共用计划。重复确认禁用。
6. 「撤销上次应用」整批恢复本批日期并移除本批新增任务。若本批记录又被修改或新增外来子任务，会拒绝覆盖。无关编辑保留。

规划历史、版本、会话连接和撤销凭据保留在当前工作台实例中，关闭侧栏后可恢复；整个工作台重载或退出后不保留这份内存凭据。应用或撤销后继续输入，会以当时任务状态生成新预览。

1.8.1 修复了宿主运行环境/技能目录消息被误当成后续人工消息而拒收回包的问题；真正的后续人工消息、未知来源、错会话和过期任务仍会阻止导入。当前规划会话连接保持到替换或工作台实例销毁。

## 其他能力与验证

保留甘特图整段/端点拖拽、父分支平移、完成任务默认隐藏、父子层级示意、连续任务月历及年月快选。工作台不连接系统日历。

仓库根 `npm test` 包含规划、旧 AI、客户端、宿主加载契约、计划/月历模型、目录适配和包自检。CI 校验固定依赖重建后的客户端与提交文件一致。浏览器 E2E 必须显式配置隔离宿主、端口及合成数据，不能指向正式 Desktop。
