# 腾讯文档工作台

首页显示最近/我的文档与搜索。点击标题打开原网页；“加入会话”打开引用预览。账号连接和修改确认在右上角“连接设置”。

## 表格范围

连接本人的 AI 文档权限后，表格通过腾讯官方结构化 API 读取。可以切换工作表，按每页 40 行 × 12 列浏览；点击单元格，Shift + 点击扩选，或输入当前页的 A1:C8 范围，再附评论加入草稿。引用保留工作表、行列坐标、重复内容、数字 0 和 false，不把单元格串成去重的段落。

此处预览的是单元格内容，不还原合并、颜色、图片对象或整份原始版式。查看这些内容请打开原网页。

## 网页、图片和 PPT 引用

macOS 13+ 随包安装独立的“DSH 腾讯文档浏览器”。使用本人的微信或 QQ 正常登录，原网页负责显示和编辑有权限的文档。

1. 在 DSH 打开目标会话，打开腾讯文档窗口和具体文档。
2. 文字：选中正文后点“选区加入 DSH”（⌘⇧J）。没有标准文字选区时，会尝试网页自己的复制动作；仅在剪贴板确实更新后读取新内容，可能改变系统剪贴板。可复制的表格选区保留制表符和换行。
3. 图片、图表或 PPT：点“框选画面”（⌘⇧K）后拖出需要的区域，Esc 取消；也可用“当前画面”接收当前可见网页。不会自动翻页或截取整份长文档。
4. 检查原生预览，填写可选评论，点“接收到 DSH”。先保存到本人电脑，尚未发送给模型。
5. 回 DSH，在“来自网页”或输入框上方点“预览并引用”，核对后加入当前草稿。画面引用会同时添加 PNG 图片附件与来源评论卡片。原草稿和附件保留，由本人发送。

图片为当前可见分辨率；超长图片可分段框选，单次 PNG 上限 8 MiB。PPT 通过原网页切换页面后引用所需画面；当前没有复刻 WorkBuddy 的 shape/对象级选区协议。能否理解图片还取决于所选模型是否支持视觉，本次验收不自动调用模型。

普通文档正文使用富文本 Markdown 预览。若腾讯 API 未提供正文或某种类型结构，打开原网页选择文字/画面，不把空结果当作读取成功。

## 账号与本机数据

网页登录和 AI 文档权限分别保存；网页登录通过不等于 MCP 授权通过。网页选区、画面接收无需 MCP 授权；列出文档、读取整篇/表格以及 AI 操作需要在连接设置完成本人的 API 授权。修改先产生具体提案，经本人确认才执行。

WebKit 正常保存网页登录；插件不读取或导出 Cookie。仅在本人点击时接收选区/画面，不后台采集。私有接收箱为本人 DSH home 的 `storages/tencent_docs/web-inbox`，JSON 和 PNG 使用 0600 权限；忽略或成功加入草稿后清理该条接收文件。图片先交给宿主原生草稿附件服务，用户发送时才交给模型。

## 兼容和验收边界

- 固定 Desktop 0.11.1；普通插件没有同面板原生浏览器接口，目前是独立 WebKit 窗口。
- 面板“网页”iframe 是实验入口；跨站策略可能阻止登录，父面板也不能直接读取跨域选区。
- 独立窗口需 macOS 13+；Intel 可构建，Intel 真机与 Apple 公证未完成。
- 只接收 HTTPS `docs.qq.com` 具体文档，保留工作表参数并移除授权参数；不引用登录页。
- 已用本人提供的六工作表大表验证真实 API 范围读取、网页登录保留、图片页显示和框选接收；没有取得真实 PPT 样例，PPT 画面仅用合成样例验证。
- 安装与代码测试不等于界面验收；新版插件需 DSH 空闲后重启，再核对引用卡片及原生图片附件。详见 [验证记录](VERIFICATION.md)。
