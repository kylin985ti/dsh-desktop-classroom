# 腾讯文档工作台

打开 DSH 的“腾讯文档”先看到最近文档和我的文档，可搜索、预览正文并加入当前会话。账号连接和修改确认留在右上角“连接设置”。

## 网页登录与选区

macOS 13+ 安装器会安装独立的“DSH 腾讯文档浏览器”。它是插件自带的网页窗口，DSH 的聊天窗口仍保留。点击“打开腾讯文档”，用本人的微信或 QQ 在腾讯原网页登录，可正常阅读和编辑有权限的文档。

1. 先在 DSH 打开目标会话，再打开文档窗口。
2. 打开具体文档，在正文中选中需要的一段文字。
3. 点击“选区加入 DSH”（或 ⌘⇧J），检查接收预览，可填写附加评论，再点“接收到 DSH”。
4. 回到 DSH，在输入框上方的“来自网页”点击“预览并引用”，核对内容和评论后加入当前草稿。
5. 引用以卡片呈现，评论可继续编辑。原草稿和附件保留，由本人决定何时发送。

表格单元格通常由 canvas 绘制。要引用某段文字，先选择单元格，再在公式栏中实际拖选所需文字；只点中单元格不等于文字选区。未检测到选区会明确提示，不自动抓取整页。也可以“引用整篇”，回到 DSH 经 API 读取正文，再选择一部分。

网页选区不依赖 API 授权。独立窗口使用 WebKit 正常保存登录，插件不读取或导出 Cookie；接收发生在点击时，不后台采集正文。接收记录位于本人 DSH home 的 `storages/tencent_docs/web-inbox`，尚未加入草稿的内容不会发送给模型。

## AI 文档权限

读取整篇、列出文档以及让 AI 操作文档，需要在“连接设置”连接腾讯 API 权限。网页登录与 API 授权是两套状态，一项通过不能证明另一项已连接。修改仍先产生具体提案，经本人确认才执行；不默认重复执行结果未知的操作。

## 兼容边界

- 固定 Desktop 0.11.1；宿主未向插件提供同面板原生浏览器。当前方案为独立网页窗口和 DSH 文档工作台。
- “网页”标签的 iframe 是实验性入口。跨站登录或腾讯页面策略可能导致加载失败；无法从父面板直接读取跨域选区。需要网页登录和选区引用时使用独立窗口。
- 浏览器需 macOS 13+；Apple Silicon 为主要测试平台，Intel 真机、Apple 开发者签名和公证未完成，不保证所有腾讯文档编辑器都暴露标准文字选区。
- 只接收 HTTPS `docs.qq.com` 的具体文档地址，保留表格页签参数并移除其他查询参数。不读取登录页、密码框或整页隐藏内容。
- 新版插件仍需 DSH 空闲后重启加载；文档窗口可单独测试，不能把接收箱成功当作重启后的会话卡片已验收。
