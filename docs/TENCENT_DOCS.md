# 腾讯文档连接器

连接腾讯账号后，由你选择哪些 DSH 会话可以使用文档。输入框底部的连接图标打开腾讯文档浮层，提供本会话开关和修改审阅，平时不额外占一行。读写使用[腾讯官方 MCP](https://developer.cloud.tencent.com.cn/mcp/server/11803)，端点为 `https://docs.qq.com/openapi/mcp`。文档原版式和编辑器使用[腾讯文档官网](https://docs.qq.com/desktop/)。

## 连接自己的账号

1. 点击会话输入框底部的连接图标，选择“登录并授权”；也可从侧边栏“连接器”的腾讯文档卡片进入。
2. 点击“在浏览器确认授权”，在腾讯官方页面登录本人账号并确认授权；无需把密码、验证码或 Token 发给 AI。
3. 授权完成后自动连接账号，无需再手动配置 MCP。回到会话，勾选“本会话使用腾讯文档”后再贴入文档链接；仍需实际读取自己的文档验证业务权限。连接失败时保留授权，点击“重新连接”即可重试。

原有本机授权继续使用，支持 OAuth 自动刷新。也可在折叠的“使用个人 Token”中录入本人从腾讯获得的 Token；保存到宿主凭据库，不写入公共配置。OAuth 回调仅监听本机 `127.0.0.1:43189`，使用 PKCE 和 state 校验。重新授权或断开会关闭修改建议、清除会话启用选择，并使旧的待确认提案失效。

## 每个会话单独选择

新会话和从旧版升级后的未选择会话默认不启用。已授权时，打开连接图标并勾选“本会话使用腾讯文档”即可使用；启用后图标变蓝。取消勾选会隐藏本会话的腾讯文档工具，并阻止继续调用；账号授权、其他会话选择和已有记录均保留。选择保存在本机，重启后仍按每个会话的选择恢复，子会话不自动继承。

关闭时会取消尚未完成的本会话请求，迟到的读取内容不返回给 AI。已有待确认提案保留，可拒绝；要确认写入须重新启用所属会话。已经发给腾讯的写入可能已经执行，仍按原来的结果核对机制处理，不自动重试。账号管理页的“断开连接”才会退出整个账号。

## 在会话中使用

将自己的文档链接贴进 DSH 会话，明确要求读取或修改，例如：

> 读取这个腾讯文档链接，总结本周进展，只读，不做改动。

> 读取这个腾讯表格的工作表和 A1:C10 范围，保留行列关系，告诉我哪些事项已完成。

> 将指定单元格改为“完成”，先生成具体修改建议，等待我确认。

官方工具会作为 `mcp__tencent_docs__…` 注册给 AI，保持原有工具名映射。无需再在 MCP 管理中添加另一份可直接写入的腾讯服务。模型对工具调用的支持、腾讯账号权限、额度和文档类型都会影响结果。连接器只管理连接和确认，不复制腾讯文档的预览界面。“去会话”只回到当前会话或进入原生新会话流程，不填入或发送草稿。高级设置中保留不调用模型的只读检查。

## 修改前确认

账号设置默认关闭“允许 AI 提出修改建议”。开启只允许已选择腾讯文档的会话生成提案，当前会话的建议会自动显示在连接图标的浮层中。点击“审阅修改”，核对工具、目标文档和完整参数，再点击“确认写入腾讯文档”。拒绝不会写入；确认只执行对应 ID 的原始参数，模型不能替换确认参数或自行批准。

提案归属取自宿主真实会话，模型填写的会话 ID 不作为依据。切换会话后只显示该会话的建议；历史无归属、子会话或其他会话的待确认项保留在侧边栏“连接器”页面。状态更新由本机事件推送，不轮询会话任务，也不自动提交输入框内容。

Esc、“关闭”和“暂不执行”只关闭审阅，提案仍在待确认列表；要终止提案，请点击列表中的“拒绝”。“确认写入腾讯文档”会实际执行这一次修改。

对有明确文档 ID 的现有文档，生成提案时先读取原内容，确认时重新读取并核对；单元格设置还核对具体范围。文档已变化、权限关闭、提案被拒绝或账号变化时，尚未发出的写入会停止。删除工具不向 AI 注册。新/不明确的工具默认需确认，不能单靠服务端的只读标签绕过检查。

工具实际返回成功后记录“已执行”；需要让 AI 通过官方只读工具读回核对，不能把提案当作修改完成。网络中断或进程关闭导致结果不明确时显示“结果待核对”，先在官网/只读工具检查，不自动重试，避免重复创建或写入。

## 简化后的边界与保留

- 不再复刻文档列表、表格网格、PPT、图片预览或网页选区；不安装独立浏览器，也不嵌入跨域登录页。
- 腾讯官网负责显示和手动编辑。AI 只能读取官方 MCP 确实返回的内容，不承诺能获取图片对象、PPT 版式或官网上的全部内容。
- 更新保留原有 OAuth、提案记录、旧浏览器和 `storages/tencent_docs/web-inbox` 本机数据；不会自动迁移、删除或发送旧接收内容。旧浏览器不再与新版插件接通。
- 安装采用 Desktop 原生 generation；资料库等其他插件独立开发时，使用 `--only @local/dsh-tencent-docs`，空闲后由本人重启加载。
- 自动化测试与真实账号/界面验收分别记录，见[验证记录](VERIFICATION.md)和[验收清单](ACCEPTANCE.md)。
