# 资料库

公开插件版本：`0.4.3-classroom.1`。在原资料库目录和包名下更新，使用已有索引、草稿与文件协作历史。文件保留在本人选择的位置。

## 阅读与编辑

Markdown 打开后直接编辑，无需切换阅读和编辑标签。支持标题、列表、表格、代码与块拖动；更多菜单提供源文模式和“返回正文”。短暂停顿后自动保存，外部变化暂停写回并保留草稿；可撤销保存或另存副本。

资料导航包含最近打开、收藏、已加入文件名搜索和连接的文件夹。支持多文件标签，文件夹按需展开；不遍历整台磁盘。HTML、CSV 和 Office/PDF 保留各自的查看或编辑方式；Office/PDF 提取正文，不承诺原版式或扫描 PDF 的 OCR。

## AI 范围与修改

- 从选区进入时默认“仅这段”：所选模型收到选中内容和本次问题，选区外正文不进入模型输入。
- 主动选择“结合全文”才加入全文上下文；修改目标仍是选区。没有选区时显示“整篇正文”。
- 来源卡保留明确的选区快照。正文或磁盘版本变化后先重新选择，不把旧快照当作当前内容。
- 选区上限 12000 个 UTF-16 字符单位，问题上限 4000 个字符单位，序列化模型输入上限 300000 个 UTF-8 字节。超出明确拒绝，不静默截断；长文中的短选区可单独提交。
- 修改先展示差异，接受后才写入；拒绝不写文件。重复或跨格式选区不猜测定位，外部变化阻止旧建议覆盖新内容。

模型服务由本人配置。超时、网络、认证、额度或模型配置错误分别提示，失败保留问题与正文。安装成功不代表模型调用已连通。连续追问历史拼接、流式输出和停止请求仍在后续范围。

## 工具栏、引用与入口

格式、引用和 AI 位于同一条选区工具栏，正常图标与选中状态可见，支持键盘激活。块拖动显示实色落点线、圆点和“放到这里”提示。全局侧栏使用独立的 16×16 书本图标，随文字颜色显示；收起侧栏后仍保留图标。

引用到会话先显示来源卡，可附加要求并选择目标会话。加入原生草稿时保留已有文字与附件，不自动发送。选区引用只传该段，整文件引用只传路径，最后由本人主动发送。

**已知问题：** 鼠标拖选时浮动工具栏仍可能遮挡上方标题，定位尚未修复。0.4.3 入口图标已通过浅色、深色和收起状态的隔离预览，正式重启加载后的显示仍需复核；不将预览当作所有学员设备的完整验收。

## 更新与验收

按 [安装说明](../INSTALL.md) 获取 main 的固定提交快照后，只更新资料库：

```bash
/bin/bash "$PACK_DIR/scripts/bootstrap.sh" --only @local/dsh-library
```

安装器保留其他插件、账号、默认模型和已有数据。更新通常返回待重启；不要中断运行中的任务，空闲时由本人正常重启 DSH，再核对书本入口、直接编辑、自动保存、撤销和 AI 范围。详见 [验收清单](ACCEPTANCE.md)。

公开版保留运行时定位和纯 Python PDF 适配、pypdf 来源及许可证。仓库不分发维护者 profile、凭据、文档、会话数据或 PDF 原生可执行文件。
